# ThreadPool

Простая реализация пула потоков на C++.

ThreadPool создаёт фиксированное количество рабочих потоков, которые ожидают задачи в общей очереди и выполняют их по мере поступления.

## Назначение

Thread pool позволяет не создавать новый `std::thread` для каждой отдельной задачи.

Вместо этого:

1. При создании пула заранее создаётся несколько рабочих потоков.
2. Задачи помещаются в общую очередь.
3. Свободный поток забирает очередную задачу.
4. После выполнения поток снова переходит в режим ожидания.

Схема:

```text
                addTask()
                    |
                    v
             +-------------+
             | Queue tasks |
             +------+------+
                    |
           condition_variable
                    |
          +---------+---------+
          |         |         |
          v         v         v
      Thread 1  Thread 2  Thread 3
